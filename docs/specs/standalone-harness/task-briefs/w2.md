# Task Brief W2 — Dual-root runtime

**Owner:** `agent-runtime-engineering`

## Objective

Separate harness authority root from consuming-project workspace/evidence root, including safe launcher recovery when an inherited project-root value resolves to harness source rather than the consumer.

## Owned paths

- `.agents/runtime/**`
- `apps/context-engine/**`
- `bin/harness.mjs`
- `scripts/harness-bootstrap.mjs`
- `scripts/harness-doctor.mjs`
- `scripts/internal/**`

## Acceptance

- changes remain project-agnostic;
- no acceptance criterion is weakened by prose;
- an external consumer cwd cannot be overridden by a stale inherited project root that resolves to harness source, including another harness checkout;
- bootstrap/runtime evidence never lands in the harness because of that stale environment;
- focused validation is executable and recorded;
- handoff records changed paths, validation and residual risks.

## Validation

`npm run harness:test` plus the work-item-specific source/build check from `TEST-PLAN.md`.
