# Verify and close task
1. Use the Task Brief acceptance criteria as immutable proof targets.
2. Map each criterion to concrete executable validation or authoritative evidence.
3. Run focused validation during implementation and broader checks only when required by the criterion or shared contract.
4. Distinguish pass, fail, blocked and not-run; never convert unavailable evidence into pass.
5. Record changed paths, validation output, residual risks and contract/version deltas in the Handoff Result.
6. Completion is allowed only when every blocking criterion is proven.
