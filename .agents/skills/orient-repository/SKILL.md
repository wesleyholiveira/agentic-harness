# Orient repository
1. Read the consuming project's nearest `AGENTS.md`, README, package/workspace manifests and architecture docs.
2. Inspect only the paths needed to locate boundaries, owners, entrypoints and tests.
3. Prefer Serena/codebase-memory for structural discovery; verify material claims against source when coverage is incomplete.
4. Record relevant paths/symbols in the Context Packet instead of dumping whole files.
5. Return observed architecture, unknowns, likely specialist capabilities and evidence limitations.
